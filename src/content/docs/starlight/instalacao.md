# Como instalar o Astro Starlight

## Criando um novo projeto

Execute um dos comandos abaixo no terminal para criar um novo projeto Astro já com o tema Starlight:

### Usando npm
```bash
npm create astro@latest -- --template starlight
```

### Usando pnpm
```bash
pnpm create astro --template starlight
```

### Usando yarn
```bash
yarn create astro --template starlight
```

## Rodando o servidor de desenvolvimento

Dentro da pasta do projeto, execute:

### Usando npm
```bash
npm run dev
```

### Usando pnpm
```bash
pnpm dev
```

### Usando yarn
```bash
yarn dev
```

## Atualizando o Starlight

Como o Starlight está em beta, atualize regularmente:

### Usando npm
```bash
npx @astrojs/upgrade
```

### Usando pnpm
```bash
pnpm dlx @astrojs/upgrade
```

### Usando yarn
```bash
yarn dlx @astrojs/upgrade
```

Mais detalhes: [Guia oficial de início rápido](https://starlight.astro.build/getting-started/)
