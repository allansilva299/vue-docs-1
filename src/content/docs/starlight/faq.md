# Perguntas Frequentes

**1. O que é o Starlight?**
> É um tema de documentação para Astro, pronto para uso e altamente customizável.

**2. Preciso saber Astro para usar o Starlight?**
> Não, mas conhecer Astro pode ajudar a customizar ainda mais seu site.

**3. Posso usar componentes React/Vue/Svelte?**
> Sim, Starlight aceita componentes de várias frameworks via MDX.

**4. Como adiciono uma nova página?**
> Basta criar um novo arquivo `.md` em `src/content/docs/`.

**5. Como personalizar o tema?**
> Use as opções de configuração no `astro.config.mjs` ou crie temas customizados.

Mais dúvidas? Consulte a [documentação oficial](https://starlight.astro.build/) ou o [FAQ do Astro](https://docs.astro.build/en/faq/).
