# O que é o Astro Starlight?

O **Astro Starlight** é um tema completo para criação de sites de documentação, construído sobre o framework Astro. Ele oferece navegação, busca, internacionalização, SEO, tipografia acessível, realce de código, dark mode e muito mais, tudo pronto para uso.

## Principais recursos
- Navegação de site
- Busca integrada
- Internacionalização (i18n)
- SEO otimizado
- Tipografia legível
- Realce de código
- Dark mode
- Suporte a Markdown, Markdoc e MDX
- Extensível com componentes de UI (React, Vue, Svelte, etc.)
