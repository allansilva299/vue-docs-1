# Componentes Prontos

O Starlight oferece diversos componentes prontos para enriquecer sua documentação:

- **Cards** e **Card Grids**
- **Asides** (notas, avisos, dicas)
- **Badges**
- **Tabs**
- **Steps**
- **File Tree**
- **Link Buttons**
- **Code blocks** com realce

## Exemplos de uso

### Aside
```md
:::note
Esta é uma nota importante!
:::
```

### Badge
```md
![badge](badge)
```

### Tabs
```md
---tabs
---tab: npm
npm install
---tab: pnpm
pnpm add
---
```
